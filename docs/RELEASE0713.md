# National Parks Explorer 0.12.2

Explorer 0.7.13 visual integration introduces a field-guide navigation bar, higher-contrast overview, responsive metric panels, park cards and readable profile and article surfaces. The atlas retains its existing data, boundaries, pointer handling, clustering and state/territory navigation. No storage schema or park reference records changed. Styles use shared platform tokens with module-local fallbacks and reduced-motion support; no external images or paid services were introduced.

Validation: TypeScript check and all 60 module tests, including the atlas interaction suite, passed. Physical-device touch and assistive-technology checks remain outstanding.
