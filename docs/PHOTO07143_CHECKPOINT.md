# Explorer 0.7.14.3 photo work — in progress

This branch is a checkpoint, not a release. The acceptance requirement is at least five accurately identified, reusable photographs for every one of the 467 catalog records. `python scripts/photo_coverage07143.py` prints the actual reviewed coverage and exits nonzero until every record reaches five. Quarantined and unreviewed candidates do not count.

NPS metadata may associate a photograph with an administrative unit while depicting another site, a painting, a poster, or a place outside the unit. Candidate download therefore does not imply approval: each image requires visual inspection and source/location and rights review before being copied into `release072z-photo07143.json` and the review ledger. `photo07143-quarantine.json` records exclusions, including conflicting descriptions. The five Pentagon Memorial photos were individually cross-checked against their permissible Commons file description pages, U.S. government credits, and public-domain declarations. Commons Action API requests are not used by the collector because the current robots policy does not permit its query endpoint.

The existing four photographs and their original metadata are preserved. Photo thumbnails remain offline, individual park pages open their own galleries, and the global gallery bounds visible thumbnails. No personal records, storage schema, atlas data or settings have been changed. Collectors are resumable, use bounded downloads and a descriptive user agent, and stop on access denial, throttling or service refusal. They save unreviewed candidates separately. Candidate image binaries are not necessarily included in this checkpoint and must be reacquired or rechecked before approval.

Rebuild generated catalog files locally with `python scripts/compile.py`; then run `python scripts/validate.py`, `python -m unittest discover -s scripts -p 'test_*.py'`, `npm run check` and `npm test`. Do not publish 0.7.14.3 or describe it as complete while the coverage gate fails. The owner’s actual records and physical device were not inspected.
