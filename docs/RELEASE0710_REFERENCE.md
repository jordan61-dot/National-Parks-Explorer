## Source review

33 targeted official NPS pages successfully retrieved and retained; zero inaccessible sources in the bounded acquisition. No nationwide source refresh. Each retained response has retrieval time, published update date when available, final URL, main text, links and response SHA-256. Curated records preserve attribute excerpts and supporting URLs.

Seven records carry newly documented source limitations, including one existing trail. Unknown numeric distances are intentionally omitted for Billy Goat A, Schoolhouse Ridge North and Heritage Trail. The Maryland Heights base route is distinguished from conflicting extension mileage. Cedar Sink route classification and Heritage Trail length/surface require caution. Descent figures are not converted into elevation gain. Great Marsh mileage has an unspecified return basis.

Accessibility descriptions retain restrictions: Calumet Dunes has slopes beyond ADA guidelines, Great Marsh’s accessible north approach is separate from its main hike, and stairs limit some other routes. Five Indiana Dunes coordinates identify documented trailheads; no park administrative points were reused.

Retained closure/construction notices at Staple Bend, Maryland Heights and Heritage Trail are dated reference evidence, not live status. Check official conditions before travel. Generic hiking categories, unsupported measurements, inferred difficulty and map-guessed coordinates were excluded. No new records were added for already well-covered New River Gorge or Cuyahoga Valley merely to increase totals.
