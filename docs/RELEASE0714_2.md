# National Parks Explorer 0.13.1 / Explorer 0.7.14.2

Adds an offline field-photo gallery across the four existing bundled NPS photographs. The gallery includes captions, rights/source links, previous/next buttons, keyboard arrow navigation, thumbnail selection, park profile links, a close control, and a failure message if an asset cannot display. It does not attach photographs to the wrong parks or read personal photographs.

Adds six subject collections built only from documented fields in the existing reference: official historic, battlefield, military park, coast, river and scenic-trail designations, and recorded historic-site, museum, fort, battlefield, waterfall, trail, overlook and cave attraction types. The UI explains this rule and warns that records are incomplete. These are starting points, not claims of comprehensive subject coverage. They combine with existing geography, classification, status and search filters and can be cleared. Keyword searches remain explicitly labeled as text searches.

No reference data, personal records, storage contracts, geographic engine, assets, dependencies or paid services change. Only the four already licensed photographs are available; this is a cross-park gallery, not a multi-photo collection for each park. Physical Galaxy S26, touch, TalkBack and comprehensive accessibility conformance still require independent verification.
