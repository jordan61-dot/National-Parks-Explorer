# Public reference provenance

Roster retrieved October 27, 2026; article and place evidence retrieved October 28, 2026. `scripts/evidence/date.txt` records the roster timestamp; individual records preserve their retrieval timestamps. The official roster reports **434 National Park System units** and lists **33 affiliated areas**, stored separately. It lists 64 units in the National Parks designation. Counts are read from the source headings, never substituted with an anticipated count.

- Inventory and classifications: https://www.nps.gov/aboutus/national-park-system.htm
- Park text and research links: each unit's linked official NPS page; extracted metadata is retained in `scripts/evidence/pages.json`.
- Offline article excerpts: official NPS history/culture, nature/geology, accessibility, directions/access, and activities/trails pages. `scripts/evidence/details.json` preserves bounded excerpts, source URLs, retrieval timestamps, published update dates when present, and failed retrievals. These are source excerpts, not complete articles or live conditions.
- Named attractions: official NPS place pages linked from those articles. `scripts/evidence/places.json` retains verified page titles and bounded excerpts. Generic link labels such as "Full Description" are omitted unless a real place title has been retrieved. URL-derived IDs preserve references when a display title changes.
- Administrative reference points: NPS Land Resources Division, https://www.arcgis.com/home/item.html?id=e62a2420170b4452b4a334db92130220 . The query URL is recorded in `scripts/compile.py` and each point. These points are **not entrances, visitor centers, trailheads or navigable routes**. Attribution: CC BY 4.0 as stated by the published item.
- Base outlines: Natural Earth, public domain, https://www.naturalearthdata.com/about/terms-of-use/ . Geometry was part of the existing module groundwork; country/state outlines are simplified and do not show park boundaries.
- Initial trail entries: New River Gorge official hiking guide, https://www.nps.gov/neri/planyourvisit/hiking.htm . Individual official place pages are linked. Distances, difficulty, accessibility and coordinates remain unknown unless explicitly compiled from source evidence.

## Reproduction and updates

`npm run reference:build` rebuilds `src/data/parks.json` and `src/data/coverage.json` solely from committed evidence. It should produce no diff. `npm run reference:refresh` retrieves the current official roster, park-page metadata and NPS points with bounded concurrency, robots checks, response bounds and no credentials. `python scripts/details.py --refresh` refreshes article/homepage evidence; `python scripts/places.py --refresh` then refreshes linked places. Run the compiler after collection. Interrupted article collection resumes without `--refresh`; `--details-only --batch N` bounds a collection run. Review the source diff, coverage report, failed retrievals, new/renamed IDs, and references before committing a refresh. Retained supplemental hiking pages currently require explicit refresh/review; their provenance must be maintained independently. Do not label these sources as live conditions.

The roster separates parks and preserves that share an NPS code. IDs derive from the full official roster name, not the administrative code. A future rename requires an explicit alias/data migration review so personal references are preserved; do not silently collapse records.

## Observed coverage and limitations

467 total reference entries: 434 official units and 33 affiliated areas. 437 have substantive homepage introductions and 429 have an unambiguous administrative reference point. 435 entries include 1,858 article sections, with 156 named attraction records. All 2,400 candidate article URLs were attempted; 188 returned retrieval or verification errors. 201 linked place pages supplied verified titles; only places associated with the selected profile evidence are included in the compiled catalog. The generated [coverage report](src/data/coverage.json) records topic totals and retrieval failures. Missing and ambiguous values remain missing. Each profile identifies unavailable offline article topics and links its source evidence.

Article excerpts cover history, nature, accessibility, directions and activities where substantive official text was available. This is not exhaustive encyclopedia or trail coverage: structured establishment dates, route distances, difficulty, accessibility attributes, licensed park photographs and individual attraction coordinates remain incomplete. No real-time closures, travel durations, bookings, park photographs, or full NPS API snapshot are claimed. Some official pages contain only headings, navigation or unavailable content; those do not count as substantive articles.

Public reference builds must never read personal visits, private historical sources, photographs, backups, credentials or Explorer's private fixtures. No API key or subscription is required.
